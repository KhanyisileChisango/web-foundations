# QuickNotes 📝

## Description

QuickNotes is a simple, user-friendly note-taking web application built with HTML, CSS, and JavaScript. It allows users to create, search, and delete notes while keeping track of character and word counts. The application uses browser local storage to save notes, restore drafts, and remember theme preferences, making it a practical project for learning front-end web development.

## Features

- **Create Notes:** Add notes with automatic IDs, categories, and creation timestamps.
- **Delete Notes:** Remove saved notes when they are no longer needed.
- **Search Notes:** Find notes by searching their text or category.
- **Input Validation:** Display error messages for empty notes and notes exceeding 200 characters.
- **Character and Word Counters:** Track the length of your note as you type.
- **Draft Saving:** Automatically save and restore unfinished notes.
- **Local Storage:** Keep notes and preferences saved in the browser.
- **Keyboard Shortcut:** Press Escape inside the text area to clear the current draft.
- **Responsive Design:** Use the application on different screen sizes, depending on the implemented CSS.

## How to Run Locally

1. **Download or clone the repository** to your computer.
2. **Open the project folder** and ensure it contains the following files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`

3. **Open `index.html`** in your web browser.
4. Start creating, saving, searching, and managing your notes!

No additional packages or installations are required.

**Note:** Your notes are stored in your browser's local storage. They are not automatically synchronized across different browsers or devices.

Through building QuickNotes, I gained practical experience with:

- **HTML and CSS:** Structuring a web application, styling interface elements, and implementing light and dark themes.
